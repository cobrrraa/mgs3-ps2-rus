# Metal Gear Solid 3: Snake Eater — русский перевод для PlayStation 2

Перенос русского перевода ПК-версии MGS3 (METAL GEAR SOLID: MASTER COLLECTION Vol.1) на
оригинальную PS2-версию **Metal Gear Solid 3: Snake Eater (NTSC-U, SLUS-20915)**.

Репозиторий содержит **инструменты сборки, подробное описание форматов и собственные переводы**.
Игры, её файлов и текста ПК-русификатора здесь нет: перевод собирается у себя из своего образа
игры, своей ПК-версии и своей копии ПК-русификатора (см. «Сборка»).

Проверено в PCSX2 2.8 и на реальной PS2 (OPL).

## Что переведено

| Часть игры | Где лежит на диске | Состояние |
|---|---|---|
| Субтитры катсцен | `MGS/DEMO.DAT` | переведены все 119 сцен |
| Субтитры видеороликов | `MGS/MOVIE.DAT` | переведены все 19 роликов |
| Реплики во время игры (радио, крики, Ева и т. п.) | `MGS/VOX.DAT` | 3490 блоков |
| Меню, названия и описания предметов, подсказки, окна R2/L2, крики охраны, Snake vs Monkey | скрипты уровней GCX в `MGS/STAGE.DAT` | ~1200 строк |
| Кодек: все звонки, досье, экран сохранения | `MGS/CODEC.DAT` | 8077 из 8385 строк |
| Шрифт: кириллица, ё, «», —, № | `383c45.raw` в `STAGE.DAT` | дорисован |

**Не переводилось сознательно:** надписи на текстурах (главное меню, вступительный текст,
названия камуфляжа и оружия на иконках), сообщения карты памяти, сетевые/DNAS-сообщения, названия
песен, бренд Calorie Mate, названия локаций на карте, папка `/ABC/`. В кодеке не переведены только
служебные строки, которые игрок не видит (отладочный список картинок, `radiotest`, `DUMMY`).

## Что нужно для сборки

1. **Образ PS2** — *Metal Gear Solid 3: Snake Eater*, NTSC-U, **SLUS-20915**, ровно
   4 558 848 000 байт (оригинальный Snake Eater, не Subsistence).
2. **ПК-версия** — папка `MGS3` из METAL GEAR SOLID: MASTER COLLECTION Vol.1 (в ней есть `fr/`,
   `assets/`, `us/`). Нужна в нетронутом виде: из неё берётся английский текст для сопоставления.
3. **ПК-русификатор MGS3** для Master Collection — распакованная папка (в ней свои `fr/`, `assets/`).
   Русификатор кладёт русский текст во «французский» слот ПК-версии; из него берётся основной
   перевод.
4. **Python 3.10+** (Windows проверено; Linux/macOS должны работать — путей Windows в коде нет)
   и пакеты:
   ```bash
   pip install numpy pillow zopfli
   ```
   Для отладочных инструментов дополнительно: `pip install capstone zstandard`.
5. **Шрифт Arial** (`C:\Windows\Fonts\arial.ttf`) — из него рисуются кириллические глифы.
   На другой ОС путь к TTF передаётся четвёртым аргументом `tools/make_font.py`.

## Сборка

```bash
# 1. Один раз: построить промежуточные данные (английский текст PS2, сопоставление с ПК-переводом)
python -E tools/prepare.py "Metal Gear Solid 3 - Snake Eater.iso" "путь/к/MGS3" "путь/к/русификатору"

# 2. Собрать русский образ (оригинал не изменяется, создаётся копия)
python -E tools/build_ru.py "Metal Gear Solid 3 - Snake Eater.iso" work/iso/MGS3_RU.iso
```

Сборка занимает ~10 минут. В конце она сама проверяет результат; для полной сверки:

```bash
python -E tools/gcx_verify.py ORIGINAL.iso work/iso/MGS3_RU.iso work/gcx/gcx_ru.json work/gcx/gcx_short.json --codec-layout work/codec/layout.json
cd work/subs && python -E ../../tools/verify_demo.py ORIGINAL.iso ../iso/MGS3_RU.iso subs_ps2_ru.csv ps2_en.jsonl translations_new.json edits.json vox_auto.json vox_edits.json vox_rules.json wraps.json --vox-blocks vox_blocks.json
```

Сборка воспроизводима: из чистой копии репозитория получается побайтно тот же образ.

### Запуск

- **PCSX2:** открыть `MGS3_RU.iso`. Игра определяется по CRC исполняемого файла, а он изменён,
  поэтому встроенные в PCSX2 исправления для MGS3 могут не примениться — на PCSX2 2.x проблем
  не замечено.
- **PS2 через OPL:** образ ~4,59 ГБ, на флешку FAT32 не поместится — нужна exFAT (OPL 1.2+),
  сеть (SMB) или внутренний HDD. Можно записать на DVD-5.
- **Важно:** начинайте новую игру. Сохранения из других сборок (и сохранения состояния эмулятора)
  помнят старое расположение кодека — звонки в них пойдут по-английски.

### 1. Шрифт и кодировка

Шрифт игры (`383c45.raw` в `STAGE.DAT`) — 2-битные глифы высотой 24 px. Кириллица кладётся
по cp1251 (0xC0–0xFF), но с переносами: «…» на 0x9F (0x85 занят), а **М Н О П м н о п** — на
0x90–0x95, 0x98, 0x9A. Причина последнего: при загрузке резидентного скрипта игра «по-японски»
обходит строки и меняет коды страниц глифов (`b & 0x9F` = 0x8C–0x8F → минус 4), портя эти буквы.
Буквы, похожие на латиницу, копируются из самого шрифта, остальные рисуются из Arial под метрики
шрифта (`tools/make_font.py`). Полный список кодов — `tools/encoding_ru.py`.

### 2. Патч исполняемого файла

`SLUS_209.15` упакован zlib-заглушкой. В распакованном коде 14 копий разбора текста считали любой
байт ≥ 0x80 началом двухбайтового (японского) символа. Условие заменено на «байт − 0x80 < 0x10»:
однобайтовыми стали 0x90–0xFF, двухбайтовыми остались 0x80–0x8F (перенос строки `80 7C`, кана и
значки кнопок `81–83 xx`, страницы глифов `84–8F xx`). Ещё поднята граница отрисовки глифа, чтобы
выводились «ю» и «я» (0xFE/0xFF). Код сжимается обратно в то же место; размер файла не меняется
(`tools/exe_patch.py`, проверяет каждую инструкцию перед заменой).

### 3. Субтитры (DEMO, MOVIE, VOX)

Записи: `u32 start, u32 end, u32 0, u16 len, u16 lang, текст`. Субтитры PS2 и ПК сопоставляются
по времени и английскому тексту (`ps2_subs.py`, `pc_subs.py`, `match_subs.py`). Вставка идёт
внутри исходных блоков без сдвига остального файла (`apply_subs.py`). Окно субтитров — 512 px:
строки шире переносятся автоматически (`autowrap.py`), для VOX действуют сокращения
(`vox_autoshort.py`, `vox_edits.json`, правила `text_rules.py`).

### 4. Скрипты уровней (GCX) в STAGE.DAT

`STAGE.DAT` — страницы, зашифрованные XOR-LCG, с секциями zlib (алгоритм — по проекту
[Shagohod](https://github.com/Jayveer/Shagohod), перенесён на Python в `tools/stagedat.py`).
Внутри каждого уровня — скрипт GCX: таблица ссылок на строки и сами строки, зашифрованные потоком
`state = state × 0x7D2B89DD + 0xCF9`. Найденные подвохи:
- строки, идущие подряд, — «цепочка»: меню берут следующий пункт сразу за нулём предыдущего,
  поэтому цепочки переупаковываются без промежутков, а не дополняются нулями;
- резидентный скрипт `r_sna01–03` (описания оружия и снаряжения) загружается только в пределах
  исходного размера — его тексты сокращены, чтобы уложиться, и перенесены по ширине окна R2/L2
  (5 строк × 366 px, `gcx_short.py`);
- более длинные строки других скриптов дописываются в конец файла, ссылки перенаправляются;
  секция пережимается zlib/zopfli в прежний объём страницы (`stage_repack.py`).

### 5. Кодек (CODEC.DAT)

`CODEC.DAT` — 2356 скриптов GCX подряд с тем же шифром. Отдельного оглавления нет: звонок
задаётся 32-битным идентификатором прямо в байт-коде скриптов уровней (тег `0x0A` + u32):
младшие 24 бита — смещение скрипта / 16, старший байт — размер чтения в единицах 8 КБ. Найдено
отладчиком PCSX2 (точка останова на запись в контекст модуля кодека).
- Скрипты пересобираются с русским текстом, CODEC.DAT растёт на ~1 МБ. Вплотную за ним лежит
  `SLOT.DAT`, поэтому файл переносится **в конец образа**: правятся записи ISO9660 и UDF
  (File Entry, Partition Descriptor, якорь UDF с пересчётом CRC) — `iso_relocate.py`.
- Все 8200 идентификаторов в скриптах уровней пересчитываются так, чтобы чтение покрывало те же
  скрипты, что и раньше (`codec_build.py`); без перевода пересчёт даёт исходные значения.
- Перевод берётся из ПК-русификатора (`codec_align.py`: в ПК-файле английские строки, затем те же
  по-французски; русификатор заменил английские), значки кнопок ПК заменяются названиями кнопок
  PS2 (`codec_buttons.py`), строки шире окна (560 px, до 4 строк) переносятся (`codec_wrap.py`).

## Состав репозитория

```
tools/          все инструменты (Python); у каждого в начале файла описание и строка Usage
  prepare.py    промежуточные данные из образа, ПК-версии и русификатора
  build_ru.py   полная сборка русского образа
  ...           разбор форматов, вставка, проверки, отладочные (disasm.py, xref.py, p2s_extract.py…)
docs/           подробное описание каждого этапа
work/subs/translations_new.json   свой перевод ролика m010_030_m020 (у русификатора файл пустой)
work/subs/edits.json              сокращения и правки субтитров катсцен под ширину экрана
work/subs/vox_edits.json          сокращения реплик VOX
work/subs/vox_auto.json           автоматические сокращения реплик VOX
work/gcx/gcx_manual.json          свой перевод строк GCX, которых нет в ПК-версии, и правки
work/gcx/gcx_short_manual.json    короткие версии описаний оружия/снаряжения для окон R2/L2
work/codec/codec_manual.json      свой перевод ~200 реплик кодека, правки, кнопки, досье
```

Всё остальное в `work/` создаётся `prepare.py` и `build_ru.py`.

### Полезные инструменты для исследования

| Инструмент | Что делает |
|---|---|
| `isols.py ISO [PATH OUT]` | список файлов образа / извлечение файла |

## Если хочется продолжить или повторить для другой игры серии

- Сначала прочитайте `docs/` — там описано не только «как», но и «что не сработало и почему».
- Для проверки в игре удобны сохранения состояния PCSX2: `p2s_extract.py` достаёт из них память,
  где видно, во что превратились строки после загрузки (так найдены порча букв в резидентном
  скрипте и хвосты, не попавшие в память).
- Отладчик PCSX2 2.x включается через «Инструменты → Показывать дополнительные настройки» и
  работает только в том экземпляре эмулятора, где запущена игра.
