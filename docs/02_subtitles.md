## Результат

**Таблица:** `work/subs/subs_ps2_ru.csv` (UTF-8 с BOM, разделитель `;` — открывается в Excel).

| Колонка | Смысл |
|---|---|
| `id` | Порядковый номер строки на PS2 (ключ для правок) |
| `ps2_file`, `ps2_offset` | Где лежит запись внутри `DEMO.DAT` / `VOX.DAT` |
| `start`, `end` | Тайминги (кадры), совпадают с ПК |
| `rec_len` | Текущий размер записи на PS2 (заголовок 16 Б + текст + NUL, выравнивание 4) |
| `en_ps2` | Английский текст PS2 (`\|` = перенос строки, на диске `\x80\|`) |
| `ru` | Русский перевод из ПК-русификатора |
| `match` | `exact` — тайминг+текст; `text` — только текст; `manual` — ручная правка |
| `variants` | >1, если у этой английской строки в ПК несколько разных переводов (взят первый подходящий) |
| `pc_file`, `pc_idx`, `en_pc` | Откуда взят перевод |
| `en_bytes`, `ru_bytes`, `capacity`, `overflow` | Размеры в байтах при однобайтовой кодировке |
| `note` | Пояснение для ручных правок |

## Статистика

| «Цепочек» записей, где RU не влезает целиком | 27 из 119 (до +48 Б) | 748 из 3514 (до +24 Б) |

- 5982 строки сопоставлены точно (тайминг + текст), 4 — по тексту, 4 — вручную (`work/subs/overrides.json`):
  - #128–129: на ПК фраза про «Шагоход» разбита на строки иначе;
  - #2427, #3840: на ПК вместо «R1/R2» иконки кнопок.
- В 4 строках иконка «кнопка действия» (U+E083) заменена словами «кнопку действия».
- Набор символов RU: латиница/ASCII + 63 буквы кириллицы (нет `Щ`, `Ъ`, `Ё` заглавных — но в шрифт их стоит добавить всё равно).
- Перевод в среднем **короче** английского, но построчно часто длиннее.

## Что это значит для вставки

- **DEMO.DAT:** записи идут плотными цепочками. В 92 из 119 цепочек русский текст влезает,
  если перераспределить место внутри цепочки. Для остальных 27 нужно понять заголовок блока
  (`83 03 74 00 07 00 00 00 …` перед первой записью) и раздвигать блок либо сокращать текст.
- **VOX.DAT:** каждая реплика — маленький блок с заголовком (`04 00 00 00 30 00 00 00 …`),
  за которым идут нули до конца сектора. Скорее всего, место для роста есть — нужно
  только корректно обновить поле размера в заголовке.
- Отдельно нужно решить кодировку кириллицы (байты 0x80+ на PS2; `0x80` уже занят под перенос строки).

> **Итог:** DEMO и MOVIE — записи раскладываются заново внутри своего блока (меняется только поле
> размера записей), не влезшие реплики сокращены (`work/subs/edits.json`); VOX — то же с учётом пар
> записей lang 1/lang 7 и «хвостов» блока, плюс автосокращения. Все 119 сцен, 19 роликов и 3490 блоков
> VOX вставлены — `05_font_and_subs_insert.md`. Кодировка — `03_font_encoding.md`, `04_exe_patch.md`.

## Как пересобрать таблицу

Сейчас эти шаги (кроме отчётов `review_subs.py` и `run_fit.py`) выполняет `tools/prepare.py`.

```
python -E tools/ps2_subs.py "games/Metal Gear Solid 3 - Snake Eater.iso" work/subs/ps2_en.jsonl
python -E tools/pc_subs.py "<ПК>/MGS3" MGS3_rus work/subs/pc_en_ru.jsonl
python -E tools/make_overrides.py work/subs/pc_en_ru.jsonl work/subs/overrides.json
python -E tools/match_subs.py work/subs/ps2_en.jsonl work/subs/pc_en_ru.jsonl work/subs/subs_ps2_ru.csv work/subs/overrides.json
python -E tools/review_subs.py work/subs/subs_ps2_ru.csv work/subs/pc_en_ru.jsonl work/subs/review.txt
python -E tools/run_fit.py work/subs/subs_ps2_ru.csv
```

Отчёт для ручной проверки: `work/subs/review.txt` (слабые совпадения, разные варианты перевода, самые длинные строки).
