# Кодек (CODEC.DAT), этап 7 — в работе

## Формат (разобран 24.10.2026)

- `CODEC.DAT` (29,8 МБ, LBA 1427154, сразу за ним `SLOT.DAT`) — **просто 2356 скриптов GCX подряд**,
  каждый с меткой `BE BA 65 41`, выровнены по 16 байт. У большинства нет таблицы процедур
  (`FFFFFFFF` сразу после метки) — `tools/gcx.py: sec2_offset` теперь ищет маркер с +4.
- Строки зашифрованы тем же шифром, что и в GCX уровней (`tools/gcx.py`), seed у всех `0x41822C07`.
  Таблица строк `0x80000000|смещение` — тоже как в GCX.
- Скрипты 0–15 — служебные/отладочные (`radiotest`, японские тестовые строки, список картинок
  `No:1/264 ... radio_picture`). Реплики, досье (`PERSONAL DATA`), экран сохранения — в остальных.

Инструмент: `tools/codec_dat.py CODEC.DAT OUT.json` — список скриптов и все уникальные строки.

## Как игра находит звонок (найдено отладчиком PCSX2)

Отдельного оглавления нет. Звонок задаётся **32-битным идентификатором прямо в байт-коде
скриптов уровней** (тег `0x0A`, затем u32 LE; байт перед тегом — 0x36…0x3A, у больших чтений
0x6E/0x7A). Функция модуля кодека (`0x387EC8` в сохранении `work/ss/call2.p2s`) раскладывает его:

```
low    = id & 0xFFFFFF            смещение скрипта в CODEC.DAT / 16
sector = low >> 7                 читается файл №1 (codec.dat) с этого сектора
script = buffer + ((low << 4) & 0x7FF)
size   = ((id >> 24) + 1) * 0x2000   байт чтения: обычно минимум + 8 КБ; ~100 ссылок читают
                                     сразу много скриптов подряд (до 110 × 8 КБ)
```

8200 ссылок на 2343 скрипта; 12 скриптов не упоминаются (тесты и дубли досье).
Как искали: точка останова на запись в поле контекста кодека (`0x1C00AB8`), затем разбор
вызывающей функции. Отладчик PCSX2 2.8 появляется после «Инструменты → Показывать
дополнительные настройки»; работает только в экземпляре, где запущена игра.

## Вставка (`tools/codec_build.py`, `tools/iso_relocate.py`, шаг 6 `build_ru.py`)

1. Каждый скрипт с 16-го пересобирается `gcx_build` (строки по цепочкам, seed 0), выравнивание 16;
   скрипты 0–15 не трогаются. Старые/новые границы — `work/codec/layout.json`.
2. Идентификаторы в байт-коде всех GCX уровней получают новое смещение и размер, покрывающий те же
   скрипты, что и раньше, с тем же запасом (`codec_build.Remap`, из `gcx_apply.py --codec-layout`).
   Без перевода переназначение даёт ровно исходные значения (проверено на всех 8200).
3. CODEC.DAT вырос на 1,1 МБ, а за ним вплотную `SLOT.DAT` — файл переносится в конец образа: на
   место якоря UDF в последнем секторе; якорь переезжает в новый конец; правятся запись каталога
   ISO9660, размер тома, File Entry и оба Partition Descriptor UDF (CRC/контрольные суммы
   пересчитываются; расчёт проверен на исходных описателях). Образ 4 589 801 472 Б (DVD-5 ≤ 4,7 ГБ).

## Ширина окна (`tools/codec_wrap.py`)

Строку шире окна игра переносит сама посреди слова («территори|и,»): 563 px помещается,
584 px — нет. Предел 560 px; реплика с более широкой строкой переносится по словам заново
(до 4 строк — 4 русские строки в окно влезают). Досье и списки (больше 3 английских строк)
не трогаются. 213 реплик перенесено, 11 выходят на 5 строк — сократить вручную.

Важно для проверки: сохранения со старых сборок помнят старый адрес CODEC.DAT (таблица файлов
в памяти, `0x1C2820`) и старые идентификаторы — звонки в них идут из старой английской копии.
Проверять только с новой игры.

## Кнопки и свой перевод

- `tools/codec_buttons.py`: значки кнопок ПК (U+E08x, в cp1251-тексте как «о‚» + символ) заменяются
  русскими названиями кнопок из английского текста PS2 в том же порядке: «Действие», «Ввод»,
  «Ползти», «Оружие», «Окно оружия», «Шаг влево»…; START/L3/R3/CQC как есть. 147 строк
  автоматически, 28 (несовпадение числа кнопок) — вручную.
- `work/codec/codec_manual.json` — свои переводы и правки: 28 строк с кнопками, 192 строки, которых
  нет в ПК-версии (фильмы Парамедика, Snake vs Monkey, подсказки к боссам), 13 сокращённых до
  4 строк, досье Кэмпбелла.
- Порядок словарей в сборке: `codec_dict` → `codec_buttons` → `codec_manual` → `codec_wraps`.

Итог: переведено 8 076 из 8 385 уникальных строк. Не переведены только служебные: отладочный
список картинок (264 строки `No:…/264`, игрок их не видит), `radiotest*`, `DUMMY`, названия песен.
