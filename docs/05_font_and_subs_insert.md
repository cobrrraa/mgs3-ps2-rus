# Русский шрифт, упаковщик STAGE.DAT и вставка субтитров (этап 5)

**Статус:** сцена в самолёте (`v020_010`, 36 реплик) полностью на русском, проверено в PCSX2
(24.10.2026) — кириллица, «ё», «ю», «я», знаки препинания без артефактов. Скриншоты: `work/ru_final_*.png`.

## Шрифт (`tools/make_font.py` → `work/font/383c45_ru.raw`)

- Формат (уточнён): `info` = биты 4–9 → ширина−1, флаги 0x400 и 0x800 (хвост вниз). Шрифт 1-битный
  (используются только оттенки 0 и 3), заглавные — строки 3–20, строчные — 8–20, хвосты — до 23.
- 25 символов скопированы из шрифта: А В Е К М Н О Р С Т Х а е о р с у х (латиница), Ё ё (из Ë ë),
  … – — « ».
- 47 символов нарисованы из Arial 25 px под эти метрики (порог 1-бит, поля 1–2 px).
- 0x80–0xBF приведены к cp1251: © ® ™ ° ± § · nbsp перенесены на свои cp1251-коды, остальное пусто
  (освобождает место — кириллица шире европейских букв).
- Данные глифов: 16 338 из 18 624 байт; размер файла и смещение блока каны не изменились.
- Превью: `work/font/preview_ru.png`.

## Упаковщик STAGE.DAT (`tools/stage_repack.py`)

Заменяет файл внутри секции на месте: расшифровка → распаковка → замена → zlib 9 → шифрование.
Заголовки, размеры секций и страниц не меняются (сжатый поток дополняется нулями до прежнего размера).
Шифрование = тот же XOR-поток, первые 2 байта — исходная «соль» ключа.

```
python -E tools/stage_repack.py ISO all 383c45.raw work/font/383c45_ru.raw
```

Шрифт заменяется во всех 5 копиях (`init`, `net`, `r_sna01..03`), каждая влезла с запасом.
Проверка: обратная распаковка даёт тот же файл байт в байт.

## Ещё одна правка кода

Функция отрисовки глифа пропускала коды 0, 0xFE, 0xFF (`sltiu t7,t7,0xFD` по адресу 0x11E5C4) —
из-за этого исчезали «ю» и «я». Граница поднята до 0xFF (`tools/exe_patch.py`, `BLIT_RANGE`).

## Вставка субтитров DEMO.DAT (`tools/apply_subs.py`)

Блок субтитров: 24 байта заголовка перед первой записью:

```
u32 ?, u32 4, u32 block_size = align16(24 + records), u32 first_start, u32 0, u32 records_size
```

Записи блока раскладываются заново (каждой — сколько нужно, выравнивание 4), `records_size`
обновляется, `block_size` не меняется (запас — только хвост выравнивания, до 15 байт).

| | Блоков |
|---|---|
| Всего в DEMO.DAT | 119 |
| Русский текст влезает | 103 |
| Нужно сократить | 16 (всего 232 байта) |

Сокращения — в `work/subs/edits.json` (`{id: текст}`), таблица перевода не меняется:

```
python -E tools/apply_subs.py ISO work/subs/subs_ps2_ru.csv work/subs/ps2_en.jsonl \
    [--pc-file v020_010_p0.sdt] --overrides work/subs/edits.json
```

## Видеоролики (MOVIE.DAT)

Субтитры FMV-роликов лежат в `MOVIE.DAT` (ПК: `us/movie`), формат блоков тот же. 495 реплик, 19 блоков.
Ролик `m010_030_m020` (брифинг операции, звонок Хрущёва) в ПК-русификаторе — пустой файл, его 116
реплик переведены заново: `work/subs/translations_new.json`.

## Ограничение ширины строки

Игра обрезает строку субтитров, вылезающую за **512 px** (найдено в игре: «…войну.» → «…вой»).
Английские строки — до 496 px. `tools/autowrap.py` при сборке переразбивает такие реплики на 2 строки
(порог 504 px) → `work/subs/wraps.json`; 14 реплик, не влезавших и в 2 строки, сокращены в `edits.json`.

## Реплики во время игры (VOX.DAT)

3874 реплики (охрана, рация, подсказки, голоса боссов) в 3490 блоках того же формата, но:
- поле после `start` — не всегда 0 (флаги); после записей бывает «хвост» 4–28 байт неизвестного
  назначения — сохраняется как есть;
- часть реплик записана дважды: язык 1 и язык 7 (тот же текст); копия языка 7 может лежать в
  соседнем блоке — перевод берётся у пары с языком 1 по таймингу и тексту;
- блоки находятся сканером заголовков `tools/vox_blocks.py` → `work/subs/vox_blocks.json`.

Блоки маленькие (запас — только выравнивание), поэтому 261 блок не влезал:
- `tools/vox_autoshort.py` → `vox_auto.json`: «!!!» → «!!», пробелы после «...», более короткий
  вариант перевода той же фразы из русификатора (82 строки);
- `vox_edits.json`: ручные сокращения (~220 строк: «Проклятье!» → «Чёрт!», «Смерть объекта
  подтверждаю.» → «Цель мертва.» и т. п.); «HQ.»/«HQ!» оставлены латиницей — для «Штаб» нет места;
- `tools/text_rules.py` → `vox_rules.json`: «Запрос огневой поддержки» → «Запрос артподдержки»
  во всех репликах.

Проверено в PCSX2 (24.10.2026): реплики охраны и экран гибели — на русском. Оставшиеся английские
«I see him!!», «Who's that!», «Speak!», «Answer me!» — **не VOX**: это таблица строк скрипта уровня
(GCX), найдена в памяти (EE 0x134B8A3, сохранение `vox_ru.p2s`). В `STAGE.DAT` строки GCX
зашифрованы — переводятся на этапе скриптов вместе с меню и предметами.

## Сборка

```
python -E tools/build_ru.py "games/Metal Gear Solid 3 - Snake Eater.iso" work/iso/MGS3_RU.iso
python -E tools/verify_demo.py <оригинал> work/iso/MGS3_RU.iso work/subs/subs_ps2_ru.csv \
    work/subs/ps2_en.jsonl work/subs/translations_new.json work/subs/edits.json work/subs/wraps.json
```

Файлы правок применяются по порядку: таблица → `translations_new.json` → `edits.json` → `wraps.json`.
